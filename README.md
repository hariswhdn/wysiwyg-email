## 🚀 Why WYSIWYG Email?
Stop wrestling with complex HTML tables and expensive monthly subscriptions. Build complex layouts, customize widgets, and get production-ready code in seconds.

### ✨ Key Features
* **Custom Widgets:** Create and customize UI components to match your brand.
* **One-Click Export:** Copy optimized HTML code instantly to your clipboard.
* **Broad Compatibility:** Perfectly formatted for HTML clients like Thunderbird, Outlook, and Gmail.
* **Zero Cost:** Save hundreds of dollars on premium email builders.

## 📥 Installation
```
# Clone the repo
git clone [https://github.com/your-username/wysiwyg-email.git](https://github.com/your-username/wysiwyg-email.git)

# Install dependencies
npm install

# Start development
npm run dev
```
